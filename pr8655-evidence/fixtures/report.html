Quantisation notes

A GGUF repository publishes one denoiser per quant. The text encoders, the VAE and the tokenizer live in a separate companion repository that every quant of the family shares.

What the picker reads

  • Each file is one row, at its own size.
  • A bare quant token resolves to the newest checkpoint.
  • Sharded checkpoints report the sum of their shards.

Why the line structure matters

An extractor that collapses every run of whitespace hands the model one very long line, and the preview shows exactly what the model receives.
